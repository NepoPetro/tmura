# Evidence Standard: Mathematica (Rejected)

**Status: Rejected.** Mathematica was considered as a possible environment for formal evidence, proof-of-concepts, and infrastructure validation. The project will not adopt it because its proprietary licensing limits access to the tools and makes independent auditing harder.

The earlier proposal to make Wolfram Language notebooks mandatory is withdrawn. No formal evidence is required to use Mathematica.

The project will use free and open-source tools that contributors can inspect and run. See [Computational Evidence with Julia and SageMath](Computational-Evidence.md) for the adopted direction.
