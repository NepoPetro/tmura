# Onboarding Guide

## Prerequisites

1. Node.js (v20+)
2. Git with submodule support
3. Python (Livemark)
4. Mathematica (Evidence and PoCs)

## Setup

git clone --recursive https://github.com/NepoPetro/Tmura.git
cd Tmura
npm install

## Pipeline Commands

- npm run validate
- npm run export:drawio
